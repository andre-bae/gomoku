# BACKLOG — отложенные работы с обоснованиями

Формат: что сделать / что даст / в чём проблема / почему отложено / где смотреть /
как проверить. Ничего не выброшено: каждый отложенный пункт здесь с причиной.
Приоритет: сначала ошибки силы из живых партий, потом инфраструктура, потом уборка.

## B-01 Единый бюджет узлов на ход
Что: один бюджет узлов на весь ход, общий для всех шагов конвейера.
Даст: детерминизм (арена станет доказательной) и гарантию ограничения работы хода.
Проблема: бюджеты отдельные у каждого поиска; суммарная работа не ограничена —
  один ход считался >20 минут, а арена при лимите 3с дала base–base 33% вместо 50%.
Почему отложено: правка конвейера; делать после первых найденных ошибок силы.
Где: _get_best_move_impl (ШАГ 3/4/4.5/4.6/9), search_vcf/search_vct, minimax.
Проверка: base–base арена = 50% при малом лимите; ход не превышает бюджет.

## B-02 Починка продлений поиска (порча доски) и их возврат
Что: найти лишний undo при USE_EXTENSIONS=True, починить, вернуть продления.
Даст: лекарство от горизонт-эффекта (качели оценок d5/d6 в партии game_2026_11_24).
Проблема: при включении доска теряла камни (повтор хода на занятую клетку).
  Страховка make_move убрала часть повторов, один остался. Плюс стоимость выше,
  глубина ниже (12к: 2.20с d5 против 1.57с d6).
Почему отложено: нужен инвариантный тест (B-03) и текущий код minimax.
Где: код продлений УДАЛЁН в шаге 34 — при возврате реализовывать заново, сначала B-03.
Проверка: инвариант целостности доски после поиска; самоигра без повторов клеток.

## B-06 S9 — инкрементальные кандидаты и угрозы

Даст: главный рычаг силы — дешевле узел → больше узлов в бюджете → глубже поиск.
Проблема: профиль показал, что подготовка кандидатов = 43–59% времени (cumtime),

  потому что построение узкого набора само дорого.
Почему отложено: сложная правка; сначала ошибки решений из живых партий.
Где: Board.get_candidate_moves, _order_moves, four_move_candidates/threat_move_candidates.
Проверка: профиль до/после, узлов/с, глубина, арена.
